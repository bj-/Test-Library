# 0020. sg-restricted ведёт Sonnet 5.5 в дочерних сессиях, без человека

- **Статус:** принято; заменяет п. 1 и 4 ADR [0014](0014-restricted-records-in-child-sessions.md) (в части исполнителя
  и работы человека), закрывает пробу [0019](0019-sonnet-restricted-trial.md)
- **Дата:** 2026-11-05
- **Участники:** bj, Claude

## Контекст

Проба ADR 0019 на BFF-Mobile (2026-11-05): `claude-sonnet-5-5` в дочерних сессиях сделал по `sg-restricted` всю цепочку -
генерацию, обзор применимости вместо человека, прогон, разбор трёх прогонов - без единой остановки фильтра и отказа.
Второе мнение (Codex, ChatGPT) подтвердило разбор 35/35; ошибки Sonnet - 3 неверных ожидания в новых тестах,
исправлены им же по замечаниям; вердикт «не применимо» по контракту оказался слабым местом - перепроверен по коду.
Ход и цифры - ADR 0019, «Итог пробы».

## Решение

Решение bj 2026-11-05:

1. **Исполнитель `sg-restricted`** - `executors.child.restricted_model` (`claude-sonnet-5-5`), дочерние сессии: одна
   запись (генерация) или одна часть прогона (разбор) - одна сессия. Работа человека по ADR 0008/0014 - разбор
   `groups/sg-restricted/`, тела багов `AI-доступ: restricted` (`bugs/restricted/`), решения о неприменимости, снятие
   `[DRAFT]`, перевод записей базы из `human` (`library_diff.py apply --override-human`) - тоже за ней.
2. **Условия:**
   - «не применимо» - только с проверкой **по коду продукта** (срез развёрнутой на стенде ветки, `git archive`), не по
     контракту; обоснование - в docstring спецификации со ссылками на файлы кода;
   - **новые тесты** стоп-тем - со вторым мнением внешних моделей (набор - `second_opinion_pack.py` проекта, задание -
     `docs/prompts/second-opinion/`), пока не накопится статистика (решение о снятии условия - bj);
   - дочерней сессии ставится задача и **исправлять** найденные «дефекты теста», а не только разбирать.
3. **Без изменений:** основная сессия - оркестратор «вслепую» (ADR 0014 п. 2), доступ дочерней сессии к закрытому -
   `--setting-sources user` из каталога проекта (ADR 0019 п. 4), проверка скриптами без содержимого, значения - `TD-…`
   (ADR 0009), закрытые материалы основной сессии и всем, кроме дочерних сессий `sg-restricted`, недоступны (ADR 0008).
4. **Остановка фильтра** у Sonnet - фрагмент не повторять; та же единица работы - по лестнице `claude-opus-4-8` ->
   `claude-sonnet-4-6` -> `claude-haiku-4-5`, затем человек; о переходе - bj.

## Альтернативы

- Оставить человека (ADR 0014) - узкое место, проба показала, что не нужно.
- Без второго мнения сразу - у Sonnet были ошибки ожиданий в новых тестах; пока рано.

## Последствия

- `Api/taxonomy/security-groups.yaml` - `restricted_model`; `Process/security-groups.md`, `Process/bugs.md` - разбор и
  тела багов `sg-restricted` - дочерняя сессия; память `ai-generation-restrictions`, `security-group-sessions`.
- Человек - только при остановке всей лестницы моделей и для выборочного контроля.
- Ограничения среды, найденные вторым мнением (проверка через почту, стенд с настоящим core, внешний файловый хост,
  наборы TD), - бэклог проектов, не модели.
