# 0009. Тестовые значения по ссылке: словарь отдельно от описаний, две сессии, ID в результатах и багах

- **Статус:** принято
- **Дата:** 2026-10-21
- **Участники:** bj, Claude

## Контекст

ADR 0008 закрыл от ассистента подробности записей с ограничением генерации — ценой ручных тестов `[DRAFT]`. Разбор
идеи `ideas/LookForLLMStopers/` (ChatGPT, DeepSeek, Qwen, Claude) показал: часть риска остановки дают не описания
проверок, а готовые к исполнению значения рядом с ними (строки инъекций, адреса внутренних служб, поддельные токены).
Ассистенту для генерации и разбора значения не нужны: ему достаточно назначения проверки, ID значения и вердикта.
Цель — минимизация данных для модели (как с паролями), а не обход фильтра: формулировки проверок не меняются.

## Решение

1. **Словарь** — `Api/test-data/dict/<КЛАСС>.yaml`: `id` (`TD-<КЛАСС>-NNNN`), `value`, `encoding` (raw | base64),
   `set` (набор `TDS-...`), `title` (нейтральное назначение), `records`, `source`. Формат — `Api/test-data/README.md`.
2. **В записях, тестах, результатах и багах — только ID.** В записи — ссылка `TD-...`/`TDS-...` в тексте; в запросе
   коллекции — `{{TD-SQLI-0001}}`. Публичный индекс без значений — `Api/taxonomy/test-data-index.yaml`.
3. **Две сессии — разрыв контекста.** Сессия сбора (в Test-Library) находит значения в записях, резервирует ID
   (`test_data.py next-id`), пишет пары «ID — значение» в `test-data/inbox/` (запись есть, чтения нет) и меняет
   значения в записях на ID. Сессия словаря (открыта в `Api/test-data/`) видит только словарь — без инструкций, что
   делать со значениями: принимает inbox (`ingest`), проверяет дубли, назначение и наборы. Порядок и промпты —
   `Process/test-data.md`.
4. **Доступ:** в сессиях Test-Library словарь и `build/` закрыты на чтение и запись, `inbox/` — на чтение
   (`.claude/settings.json`); сессия словаря не читает библиотеку (`Api/test-data/CLAUDE.md`, её `.claude/settings.json`).
5. **Подстановка на лету** (вариант 2 идеи): коллекция всегда без значений. newman — движок `test-engine` 0.4.0
   кладёт словарь в окружение раннера; Postman — человек импортирует `test-data/build/test-data.postman_environment.json`
   (`test_data.py env`). Ссылка без значения — запрос не отправляется (PostmanScripts, `TEST DATA MISSING`).
6. **Обратная замена:** движок меняет значения словаря на `[ID]` во всех результатах (`results.json`, `raw/`,
   консоль, отчёт) всегда, в том числе в URL-, HTML-, JSON-кодировке и base64.
   **Тело ответа** (уточнено 2026-10-21, bj): модель видит его очищенным, кроме значений с `response: hidden` — их
   тело движок заменяет пометкой (ID, длина) и в `results.json`, и в `raw/`. Умолчание по классу (`test_data.py`):
   PATH, SSRF, XXE — `hidden` (сервер может вернуть свои данные: файлы, ответы внутренних служб), остальные —
   `visible`; у значения можно переопределить. **Вердикт** считает скрипт теста: признак срабатывания `detect`
   (регулярное выражение, заполняет сессия словаря; не совпадает с самим значением) — `test("notExecuted")`
   PostmanScripts; задержка — по времени ответа.
7. **Баги** — ID значения и вердикт; значение человек смотрит по ID: `test_data.py html` (страница
   `test-data/build/index.html`; позже — pages, KB или свой сервис). Дубли — по ID (`autotest.py dupes`).
8. **Выгрузка для внешних LLM** — `tools/export_for_llm.py`: архив без `restricted/`, словаря, `inbox/`, `build/`,
   закрытых блоков; с заданием — файлы из его заголовка.

## Альтернативы

- Подстановка до запуска (вариант 1 идеи): значения оседают в коллекции, которую ассистент читает и правит; отклонено.
- Нейтрализовать формулировки («обработка спецсимволов» вместо «SQL-инъекция») — DeepSeek, Qwen: это обход, теряется
  смысл для человека и связь с OWASP/CWE; отклонено (как в ADR 0008).
- Одна сессия и для сбора, и для словаря: значения и инструкции по их применению в одном контексте — то, от чего
  уходим; отклонено.

## Последствия

- Записи со значениями переписываются на ID — сессией сбора, по одной теме за раз.
- Запрет в `settings.json` — защита от случайного чтения, не абсолютная (как в ADR 0008).
- Обратная замена не узнает значение, переработанное сервером до неузнаваемости: поэтому вердикт — в скрипте теста.
- Сценарии «серия попыток» (перебор, OTP, лимиты) словарь не закрывает — для них примитив фреймворка
  (задание `PostmanScripts/docs/tasks/attempt-limit.md`), до его готовности — `[DRAFT]` по ADR 0008.
- Разбор идеи — `ideas/LookForLLMStopers/LLM-Claude.md`.
