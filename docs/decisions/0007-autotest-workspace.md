# 0007. Рабочее место Autotest, движок test-engine, новая раскладка прогонов

- **Статус:** принято (дополняет [0003](0003-test-runs-and-bugs.md): пп. 3 и 4 — хранение прогонов и багов)
- **Дата:** 2026-10-19
- **Участники:** bj, Claude

## Контекст

Прогоны и отчёты складывались как попало: две разные раскладки (BFF — `postman` + `test-runs`, VPN13 — всё внутри
`13vpn`), копии скриптов в обоих проектах, одинаковые номера багов в разных проектах, в прогоне нет сборки продукта,
сырьё прогонов в git (~10 МБ на полный прогон). Рассмотрение — [`Ideas/TestGeneration/LLM-Claude.md`](../../../Ideas/TestGeneration/LLM-Claude.md) (репозиторий `Ideas`),
решения пользователя — часть 3 (разделы 16–21).

## Решение

1. **Рабочее место** `C:\Git\Autotest\`: `test-engine\` и `projects\<КОД>\{tests, results}`; `Test-Library` — в `C:\Git`.
2. **Движок** — отдельный приватный репозиторий `test-engine`; проект описывает себя в `autotest.yaml` и фиксирует
   версию движка; вызов — `python autotest.py <команда>` из корня репозитория тестов.
3. **Результаты** — отдельный репозиторий на проект (BFF — gitlab.viiitech.ru/test/autotest/bff, вместо `test-runs`):
   `runs/<YYYY>/<MM>/<RUN-ID>/` с манифестом `run.yaml` (кто/как запустил, стенд, сборка продукта, коммиты тестов,
   движка и библиотеки), `runs/index.jsonl` + `INDEX.md`, `bugs/`, `history/`. `raw/` и Allure — не в git.
4. **Коды проектов**: `BFF` (модули — суффиксами: `BFF-Admin`, `BFF-Admin-Auth`), `VPN13`. RUN-ID —
   `<КОД>-<YYYYMMDD-HHMMSS>-<набор>`, номер бага — `BUG-<КОД>-NNNN`.
5. **tinySmoke** — первый шаг прогона (поле `gate` набора): нет ответа или упала ключевая проверка — билд битый,
   остальное не запускается. **X-Request-ID** `<RUN-ID>/<тест>` в каждом запросе — для поиска в логах стенда.
6. **Переезд минимальный**: из `test-runs` перенесены баги, отчёты двух опытных прогонов, на которые они ссылаются
   (`archive/runs/`), и история Allure; история репозитория `test-runs` не нужна — его можно удалять.

## Альтернативы

- Один общий репозиторий результатов на все проекты — проще, но смешивает доступы (VPN13 — другой отдел).
- Движок в `Test-Library/tools` — один клон, но версия движка «размазана» по частым коммитам библиотеки.
- Сырьё прогонов в Git LFS / GitLab Packages / S3 — отложено: `results.json` хватает, сырьё остаётся на машине.

## Последствия

- VPN13 пока на своих копиях скриптов (свой фреймворк Bearer JWT) — перевод на движок отдельно.
- Пути в правилах `Process/`, памяти и навыке `create-tests-api` указывают на новую раскладку.
- На новой машине — клонировать `test-engine` и репозитории проекта в `C:\Git\Autotest` (README движка).
