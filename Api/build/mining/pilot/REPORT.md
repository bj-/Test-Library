## Наблюдения

- **nest и express** закрывают исправленное без привязанного PR («fixed in vX» в комментарии). Для них включён
  `allow_no_fix`, записи помечены `fix_evidence: closed-completed`. Тестов из фикса у них почти нет, поэтому
  качество этих записей проверит триаж.
- **Strapi и Directus** — только 2026 год (150 самых новых закрытых). Для масштабирования стоит брать и старые.
- **express** — среди `bug` встречаются баги сайта и документации (expressjs.com), их отсеет триаж.
- После фильтра 696 записей, больше целевых 300–500: GHSA даёт 200 — это ценные записи с CWE, оставлены целиком.
