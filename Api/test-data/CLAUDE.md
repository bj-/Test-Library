# Сессия словаря тестовых значений (ADR Test-Library 0009)

Сессия, открытая в этом каталоге, работает **только со словарём**: `dict/`, `inbox/`, `build/`, `README.md` и
скриптом `../tools/test_data.py`. Порядок работы — раздел «Сессия словаря» в `Test-Library/Process/test-data.md`
(промпт там же); формат — `README.md`.

- Не читать библиотеку: `../checks/`, `../restricted/`, `../ideas/`, `../mining/`, `../build/`, `C:/Git/Ideas/`
  (запрет — `.claude/settings.json`). Записи библиотеки меняет только скрипт (`ingest`, `merge` — замена ID).
- Словарь — справочник: ID, значение, назначение, набор. Не дописывать, как и где значение применять, не придумывать
  новые значения (их добавляет человек или сессия сбора), не пересказывать значения в ответах — только ID.
- Назначение (`title`) — нейтральное и короткое, без самого значения: оно уходит в публичный индекс.
- Коммит — `dict/`, `../taxonomy/test-data-index.yaml` и записи, изменённые скриптом; сообщение на русском.
