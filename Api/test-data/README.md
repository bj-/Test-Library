# Словарь тестовых значений (ADR 0009)

Значения, которые тест подставляет в запрос (строки-нагрузки, наборы, токены, адреса), хранятся здесь и только здесь.
В записях библиотеки, коллекциях, результатах прогонов и багах — только ID. Решение —
`docs/decisions/0009-test-data-by-reference.md`, порядок работы и промпты сессий — `Process/test-data.md`.

| Каталог | Что | Сессии Test-Library | Сессия словаря (открыта здесь) |
|---|---|---|---|
| `dict/<КЛАСС>.yaml` | словарь | закрыт | читает и правит |
| `inbox/*.yaml` | новые пары «ID — значение» от сессии сбора | только запись нового файла | принимает (`ingest`) |
| `build/` (не в git) | окружение Postman, страница для человека | закрыт | собирает (`env`, `html`) |

## Формат записи словаря

```yaml
- id: TD-DEMO-0001          # TD-<КЛАСС>-NNNN; ID резервирует `python tools/test_data.py next-id <КЛАСС> [N]`
  value: "..."              # значение как есть
  encoding: raw             # raw (по умолчанию) | base64 - значение в base64: двоичное, управляющие символы, пробелы по краям
  set: TDS-DEMO-BASIC       # набор: тест может взять все значения набора
  title: короткое назначение без самого значения    # попадает в публичный индекс
  records: [INJ-DEMO]       # записи библиотеки, где значение используется
  source: library           # library | ссылка на публичный корпус
  response: visible         # visible | hidden - видит ли модель тело ответа (очищенное); умолчание по классу:
                            #   PATH, SSRF, XXE - hidden, остальные - visible (ADR 0009, п. 6)
  detect: 'regexp'          # признак срабатывания в ответе (вывод команды и т. п.) для test("notExecuted");
                            #   не должен совпадать с самим значением - иначе отражение даст ложное срабатывание;
                            #   синтаксис JavaScript (new RegExp): без (?i) - регистр через [Uu]sage
  added: 2026-10-21         # ставит ingest
```

Файл `inbox/<ГГГГ-ММ-ДД>-<тема>.yaml` — список таких же записей (без `added`).

## Как значение доходит до запроса

- Запрос коллекции: `{{TD-DEMO-0001}}`; набор — `{{TDS-DEMO-BASIC}}` (JSON-список ID).
- newman (`autotest.py run`): движок `test-engine` берёт словарь отсюда и кладёт в окружение раннера; в результатах
  значения заменяются обратно на `[TD-DEMO-0001]`.
- Postman вручную: `python tools/test_data.py env` → импортировать `build/test-data.postman_environment.json`.
- Человеку посмотреть значение по ID: `python tools/test_data.py html` → `build/index.html`.
- Ссылка без значения — PostmanScripts не отправляет запрос (`TEST DATA MISSING` в консоли).

Публичный индекс без значений (ID, назначение, набор, записи, длина, хеш) — `taxonomy/test-data-index.yaml`.
