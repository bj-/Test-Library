# От человека для LMM / Claude

Цель: Генерация качественных идей, с перекрестной проверкой и дополнений между разными LLM.

1. В данном каталоге хранятся идеи развития проекта
2. Одна идея (идея модет быть большой) в одном каталоге
3. Изначальная идея обчно лежит в файле idea.md
4. При рассмотрении идей надо
4.1. сначала зачитать idea.md, обработать ее, записать свой вариант
4.2. В файлах "LLM-*.md" - результат рассмотрения данной идеи другими LLM оделями и своми предложениями
5. Только после независимого рассмотрения идеи - зачитывать другие мнения и пересматривать результаты с учетом других мнения.

Данный список не является безусловным сводом правил, можно его дополнять и менять. главное не тянуть одеяло на себя, а рассматривать и другие мнения.
